# raytracing.wasm

This is a project aimed at experiencing and exploring the capabilities of WASM generated from Rust, in combination with Svelte 5.

# Credits

The code used for the raytracing, as well as the theoretical concepts and much more, have been supplied by / can be read in the awesome book [_Ray Tracing in One Weekend_](https://raytracing.github.io/books/RayTracingInOneWeekend.html). The code in the book is written in C++, so the code had to be translated into Rust. Apart from differences regarding the semantics or structure of the languages, the code is for a large part the same as in the book.
